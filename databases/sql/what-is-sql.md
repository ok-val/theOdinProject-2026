# Structured Query Language

> SQL is the programming language used to communicate with a relational
> DBs.

SQL allows you to Select (find), Insert (add), Update (change), and
Delete (remove) large amount of data.

PostgreSQL is a relational database management system that uses SQL.

SQL is a **declarative language**, meaning that you describe what needs
to get done while the query are handled internally by a RDBMS.

## But is ESS-QUEUE-EL or SEQUEL

The language was called SEQUEL (pronounced S-E-Q-U-E-L). But it was
already taken so they shortened it into SQL.

This makes the SEQUEL pronunciation more historically accurate.
