# Primary Key

> [!definition] Primary key
>
> A primary key is a specific column (or combination of columns) that
> identifies every records as unique within an SQL table.
>
> In which, (1) the PK value of each record must be unique and (2) said
> value cannot be NULL or empty.

One common primary key type is an auto-incrementing integer (for being
space efficient), but it can also be a string, hashed value, so long as
it is unique.
