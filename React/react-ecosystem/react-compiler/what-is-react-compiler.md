# What is the React Compiler?

Source:

- https://react.dev/learn/react-compiler

> React Compiler is a new build-time tool that automatically optimizes
> your React app by doing all the memoization (caching) for you.

The problem it's trying to solve: Manual memoization is tedious, easy to
get get wrong, and adds extra code to maintain.

React Compiler does this optimziation atumotically, allows you to focus
on building features instead.
