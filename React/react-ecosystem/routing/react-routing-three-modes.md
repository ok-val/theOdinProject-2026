# Three modes of React Routing

Source: https://reactrouter.com/home

React Router is a multi-strategy router for React.

There are three modes to use it in an app, offering different levels of
control:

1. **Declarative**

The classic, minimalist approach using components like `BrowserRouter`,
`Routes` and `Route` to handle basic URL matching and component
rendering while leaving the data fetching and state management up to
you.

2. **Data**

This is the method covered in this file. It uses routers like
`createBrowserRouter` to integrate data fetching and mutations directly
into routing lifecycle.

3. **Framework**

The most coverage, comprehensive approach, including every from Data
mode while adding full-stack capabilities like Server-Side Rendering,
utilizing React Router to its fullest extent.
