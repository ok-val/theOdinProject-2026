# Versatility of Backend Code

Source:

- https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Server-side/First_steps/Introduction

## Big benefit

One of the most significant benefit in using a server-side code is the
_ability to tailor website content for individual users_ while making
personal preferences easier to store and improve interaction experience
(storing credit card details, personal info, history, network tree,
sending confirmation emails, notifications and updates).

All of such is a feature of dynamic sites [[static-vs-dynamic-sites.md]]

## Challenges

User agents provide inconsistent levels of compatibility with
client-side code features, making the handling a consistent experience
between client-side and server-side more complex.

## What can you do with the server-side programming?

Deliver tailored information for individual users and thereby create a
much better UX.

E-commerce apps like Amazon uses server-side programming to construct
search results, make targeted product suggestsions, simplifying
purchases.

Social network apps like Facebook, Instagram, or Pinterest use server-
side programming to highlight, share, and control access to interesting
content using an additional layer of data analysis.

Search apps like Google optimizes users' search experience based on
previous searches.

Banking apps allows sites to restrict access to authorized users and
serve only the finro that user is permitted to see.

Map apps allows users to save their favorite places and search for
travel history, highlight local businesses in search results.
