# Template engines

Source:

- https://blog.logrocket.com/how-to-use-ejs-template-node-js-application/

A template engine dynamically generates content based on two primrary
inputs:

- **Template:** contains the static document structure/content and
  templating syntax.

- **Data:** Contents that the template engine uses to replace template
  syntax

Instead of manually assembling page and compenents using vanilla JS, Web
template engines, like EJS or Pug, provide features to streamline this
workflow into something more intuitive and convenient.
