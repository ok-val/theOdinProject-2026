# EJS Glossary

Source:

- https://ejs.co/#docss
- https://github.com/mde/ejs/wiki/Using-EJS-with-Express

## Options

- `delimiter`: Character used for inner delimiter, by default '%'
- `openDelimiter`: Character used for opening delimiter, by default '<'
- `closeDelimiter`: Character used for closing delimiter, by default '>'

## Terms

- Scriptlet tags: `<$ $>`; can be customized with the options above
