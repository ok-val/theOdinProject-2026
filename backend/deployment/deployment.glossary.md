# Deployment glossary

Source:

- https://www.theodinproject.com/lessons/node-path-nodejs-deployment

- **Hosting providers:** Server landlords who own the servers and rent
  space on them to customers---the people who can use that space to
  store their websites and make them accessible to anyone on the web.

- **Host for Static vs Dynamic sites:**
  - Static sites are ones that stay the same everytime. GitHub is good
    for static sites.
  - Dynamic sites are ones that changes depending on the users. This
    would require a server-side hosting so GitHub wouldn't suffice. AWS,
    Google Cloud, Microsoft Azure, Railway, Render are some good
    providers for dynamic sites.

- **Platform as a service (PaaS):** is a specific kind of hosting
  provider that makes it easier for beginners to use than other hosting
  providers by taking care of the nitty gritty details with the
  underlying server infrastructure.
