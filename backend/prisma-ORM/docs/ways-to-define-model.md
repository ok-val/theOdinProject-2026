# Ways to Define Model

Source:

- https://www.prisma.io/docs/orm/v7/prisma-schema/data-model/models

---

There are two ways to define a Model Definition:

- **Migration:** Uses `npx migrate`. Write a fresh Data Model by hand
  and map it to the DB. Best for fresh start. Data Model becomes the
  source of truth.

- **Introspection:** Migrate from an existing SQL schema. Data Model is
  generated by introspecting the current DB. The original DB schema
  remains the source of truth.
