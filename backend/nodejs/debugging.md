# Debugging in Node.js

Source:

- https://www.youtube.com/watch?v=2oFKNL7vYV8&t=191s
- https://code.visualstudio.com/docs/nodejs/nodejs-debugging

## Use a `launch.json` file

1. Start the server
2. Attach the debugger using a `launch.json` config file
   - Said working file is in `.vscode`, this file is set to use launch
     mode so starting the server prior is not needed.

## Use JS debugging terminal

1. Create New Terminal (with Profile) or press the + next to the
   terminal button
2. Select JavaScript Debugging Terminal
3. Start the server as normal
