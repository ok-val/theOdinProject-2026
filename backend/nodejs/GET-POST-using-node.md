# GET and POST using Node

## Basic GET

I have a script for GET with fetch
[[tutorial-scripts/basic-GET-script.js]],

Simply run this script with node to see the console logging the
requested data to the CLI.

> node basic-GET-script.js

## Basic POST

There another script for POST [[tutorial-scripts/basic-POST-script.js]].

For POSTing using Fetch API, I also have to pass in the optional
`RequestInit` object as `fetch()`'s second param.

> node basic-POST-script.js
