## Summary

The Internet is a wire, buried in the ground. 
Two computers connected to this server can communicate.
Computers can be **servers that stores stuff for the Internet**.

Every computer or server is assigned with an **IP**.
IP basically tells the servers who's who and avoid confusion.
Basically, an send-receive address.

The IP works like a candy-wrapper. 
Every time it passes through a router, it gets assigned with a new wrapper.
Yes, like leaving a trace.

Our PCs are called **clients**.

facebook.com or reddit.com is a **server**.

The client do certain stuff with the server (send email, store image)
The server do certain stuff with the client (send webpage, retrieve email)
