## HTTP (HyperText Transfer Protocol)

HTTP is a server-side protocol for fetching resources (html, css, png, mp4,...).
Requests are initiated by the recipient, usually a Web browser.

![[Pasted image 20260405123308.png]]

Clients and servers exchange individual messages.
The client sends request,
and the server sends responses.

HTTP is sent over TCP (Transmission Control Protocol).
HTTP piece-meals files together, on-demand. 
It's flexible.
