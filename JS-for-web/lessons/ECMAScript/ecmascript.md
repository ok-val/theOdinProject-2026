## What is ECMAScript

JS is a programming lang that conforms to the ECMAScript standard,
made by ECMA international. 

ES6 is a version of JS that was released in the summer of 2015. 

It includes many new features that make writing JS much easier and 
cleaner.

There is some confusion about the new naming convention. TC39 tried to
change ES6 to ES2015, ES7 to ES2016, and so on.

## Browser Support

Browsers take a while to catch up with the versions release.
A new feature may take a couple of years to become "widely available",
meaning supported across the majority of modern browsers and browser 
versions in use.

So be careful with trying out new features because they may not be 
supported in your many browsers yet. 

The PROBLEM: You can't control which browsers people will use to connect
to your website

## Babel

Because you cannot control which browser or browser version people use 
to connect to your website, there is a solution called Babel. 

**Babel** = a tool that takes your modern JS code and 
*transpile* 
it to code that older browsers can understand. 

It basically enables backward compatibility.
You have to select some targets for this transpilation process.
These targets depend on who your product should serve, target audience,
and so on.

Some products should be compatible with older browsers.
Others should be compatible with newer ones. 

This is a layer of customer compatibility that I would have to worry
later on.
