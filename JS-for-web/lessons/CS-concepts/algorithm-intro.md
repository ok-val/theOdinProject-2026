## What is an algorithm

An algorithm is a set of instructions that solves a problem, step-by-step,
or procedurally. 

Think of a decision tree, an algorithm is like a mathematical expression
of a decision tree. Or a logic diagram. Or a tutorial on swimming.

There are components that repeat; some are branches of certain logic, or
counter-logic. 

For typical websites, algorithms may be not necessary. 
It only becomes critical when you have a lot of data you have to process
or transform somehow to serve some particular features of the web (e.g.
search algorithms, sorts, filters, CAPTCHA, recommendations). 

Without algorithms, it would be impossible to create scalable solutions
to complicated/complex problems that deal with lots of data.

Algorithm handles these calculations for you and make a lot of good 
features shine.
