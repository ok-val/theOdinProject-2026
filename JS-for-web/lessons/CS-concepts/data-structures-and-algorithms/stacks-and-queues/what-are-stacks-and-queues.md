## Stack

- Top / Bottom of Stack
- Elements are sorted by insertion order
- Last element in is first out (LIFO)
- Elements have no index (no direct access)
- Only work on the topmost element

## Queue

- Front / Back of Queue
- Elements have no index (no direct access)
- First element in is first out (FIFO)
- Work at both front and back end of queue
- Can be applied for website access queues, printing queues
