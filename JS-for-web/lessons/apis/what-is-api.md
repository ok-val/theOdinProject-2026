## APIS

API stands for Application Programming Interfaces.
These are INTERFACES that allows us to interface with extended features,
functionalities, and serving data. 

These APIs could be either native or from external servers.
APIs is the superset of other APIs such as WebAPIs.

There are multiple ways of requesting data from an API, 
but they do the same thing:

* Access API through a URL using a specific query (know your target 
data). Querying specifics are usually documented on the services' 
website.

You can't just use this URL like any other URLs.
They require some specific tech to use.
For example, API keys or running session.
