## View and change CSS

Here are a few tools for accessing and editing CSS using DevTools:

1. Inspect any element's properties, class, and id assignments
2. Edit CSS declaration to an existing style using the Style panel
3. Edit CSS classes to an element using `.cls` button in the Style panel
4. Edit a pseudostate to a class using the `.hov` button in the Style panel
5. Edit additional inline styles (outside style declaration) using the Computed Box Model panel
