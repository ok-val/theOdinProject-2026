Absolute units

These are always the same in any context.
`px`, `in`, and `cm` are absolute units.

Btw, this is the size of 1px.

Relative units

These units can chhange based on context.
`1em` is the font-size of the element (or the element's parent).
`1rem` is the font-size of the root element (either `:root` or `html`).
`100vh` or `100vw` is the height or width percentage of the viewport.
