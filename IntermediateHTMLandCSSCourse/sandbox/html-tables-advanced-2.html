Let's review a few more things I can do with a table following this CSS tricks tut.

  • tfoot used to go after thead and before tbody (Surprise MF!). Now tfoot order amont thead and tbody is flexible. It goes after tbody now, but goes in the middle when having a very tall table. But nah, we can use display: sticky if this doesn't concern accessibility.
  • Here are the properties that I can use for a table
    • vertical-align: align contents in a cell
    • white-space: controls how text is wrapped in a cell, combine with `&shy;`
    • border-collapse: determines if cells' border collapse among themselves, applies an order of prevalence, from most: row, rowgroup, column, columngroup, table.
    • border-spacing: specs the `margins` of cells.
    • padding: controls white-space around content per cell
    • width, border: iykyk
    • table-layout (auto | fixed): auto for content-defined width, fixed for anchoring or fixing to table width or first row's width, whichever is present.
    • I can make normal semantic elements display like a table using table's native display modes. Vice versa, I can also break table's default display style to something like inline if I desire.
    • And many more... Revisit this site when needed.
