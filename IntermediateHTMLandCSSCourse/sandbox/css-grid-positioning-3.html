Another way is to use the grid-column and grid-row shorthands

With this method, it's also possible to count backwards.
For example, see how .liv spans across all columns using grid-column: 1 / -1;

It's also possible to use the keyword `span` instead of defining an ending value.
For example, see how .live spans over two rows using grid-row: 1 / span 2;
