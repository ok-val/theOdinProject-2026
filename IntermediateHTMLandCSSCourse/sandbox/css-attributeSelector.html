These are helpful to target elements with specifc attributes.

For example, if we want to consistently target anchor element with the attribute href="www.ladudu.com" or images with scr="picture.jpg", we can do that.

Attribute selectors have the same specific system as classes and pseudo-classes (0,0,1,0).

  • [attribute] -- targets anything that has attribute (href, src) indiscrimantly.
  • selector[attribute] -- targets only the selected class or element type with that speicifc attribute
  • [attribute="value"] -- targets only elements or classes with that specific attribute and the corresponding value.

Because attributes take string as value, we can use Regular Expression to match specific string conditions. Here are three generic string conditions:

  • [attribute^="starting-value"] -- targets attributes with the specified starting value
  • [attribute$="ending-value"] -- targets attributes with the spec-ed ending value
  • [attribute*="anywhere-value"] -- targets attributes with found value anywhere inside

Remember the matching string conditions are case-sensitive. Best way is to find out through practice.
