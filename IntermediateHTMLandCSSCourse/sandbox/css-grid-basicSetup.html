Setting up a grid

A grid layout requires a parent container's display mode to be set to either:

  • grid
  • inline-grid

When a container is set to grid, only the direct child elements will become grid items. Grand children will not become grid items.

Columns and rows

To control column and row tracks, we use `grid-template-columns` and `grid-template-rows`.

These essential allows me to control the widths and heights of grid cells.

The number of values I set for these tracks corresponds with the number of columns or rows.
