There are two types of pseudo-classes: Dynamic/user-action and Structural pseudo-classes.

Dynamic / user-action pseudo-classes

These ones activate elements for interactive appearance features:

  • :focus -- element that is currently SELECTED the user with either the cursor or keyboard
  • :hover -- element that the cursor is hovering over.
  • :active -- element that is currently BEING CLICKED (mouse-down)
  • :link -- element that are wrapped by the anchor tag
  • :visited -- element(s), most likely links, that users have already clicked on.

Structural pseudo-classes

These ones selects elements based on the placement or positioning the DOM.

  • :root -- represents the top level of the document. As a class selector, it's more specific than the element selector html
  • :first-child and :last-child -- selects, respectively, the first and the last sibling.
  • :empty -- selects elements that have no children at all.
  • :only-child -- selects elements that have no sibings.
  • :nth-child(even | odd | 3 | 3n | 2n + 2) -- selects, respectively, every even element of the given class, next, every odd element, the third element, every thrid element, and, finally, every second element starting with the second element.
