Viewbox attribute

The viewBox attribute defines an internal coordinate system.
When it's provided, elements nested inside will follow this local layout mode (if you will).

The viewbox is like a viewport. You can select which part you want to look at.
It takes two pairs of values: 0 0 300 300.

  • 0 0 pair decides where the top-left corner of the viewport stays.
  • 300 300 pair is the zoom level
