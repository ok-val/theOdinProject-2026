Content first vs layout first design

A way to decide between Grid and Flexbox is to consider if your design starts from the content, or from the layout.

In content-first design, use Flexbox.

Content-first design prioritizes content clarity, the layout follows. Flexbox gives us more control and intuition to control the horizontal significance of the contents. For example, the first element on the second row would be twice as long as the rest.

Because it controls content significance, it's considered content-first design

In layout-first design, use Grid.

Layout-first design prioritizes layout control. Grid would allow us more control over exact placements of items, and the content will have to follow their cells.

Imagine a table and a list. Use grid if you want create layouts. Use flexbox when you want to list something.

This analogy is useful for thinking about how we control flexboxes and grids. While using flex can give as a 2D-table layout and grid can give a list-like layout, it is more intuitive to control tables using grid and to control lists using flex. Kevin Powell's advice is that we should choose the path of least resistance.

Nesting content-first in layout-first design

When I have different lists of elements, each to be presented in a certain layout, nest flexboxes in grid. I will have layout of lists.

Nesting layout-first in content-first design

When I have a different layouts to be presented as a list, nest grids in flexboxes. I will have a list of layouts.
