Text input

All basic text controls share some common behaviors:

  • readonly: (bool) the input can't be modified but it sent to server.
  • disabled: (bool) the input can't be modified and not sent to server.
  • autofocus: (bool) the input automatically focus on page load.
  • size: sets the physical size of the box.
  • maxlength: sets the maximum number of chars that can be entered.
  • spellcheck: performs spellcheck for user input

Single-line text fields

Input element using the type attribute of `text`, the default value.

See all of the single-line input types here.

The default style applies some colored outline for the focused and faded text for the disabled field.

Hidden content text field

There is the hidden input type. How mischievous. It's used to create an invisible form control (widget). For example, if I want wato submit a timestamp to the server stating when an order was placed, I can. This content field is not rendered nor picked up by the screen reader.
