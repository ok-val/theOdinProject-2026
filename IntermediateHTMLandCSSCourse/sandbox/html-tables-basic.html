Basic tables

Tabular data needs to be displayed using tables. YUP!

HTML tables are fully supported for screen readers and other assessibility features.

DO NOT USE TABLES FOR LAYING OUT ELEMENTS. Strange human behaviors, but I guess you would see this a lot in older websites.

You cannot sematically mark elements as easily and layout modes often harder to config.

To create a basic table:

I'm theader col 1 & 2. I'm theader col 3.
I'm the first cell. I'm the second cell. I'm the third cell.
I'm the on row 2. I'm the on row 2.
