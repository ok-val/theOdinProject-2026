Accessibility features

  • Caption: nested inside a table, displays at the beginning of table.
  • Summary: a deprecated alternative of Caption, doesn't appear on page.
  • thead, tbody, tfoot: adds semantic structure for finer control (e.g., batch CSS selectable). tbody is always added by browser by default.
  • Scope: can be added to the th element, tells screen readers exactly what cells the header is a header for. For example, is it a header for the row it is in, or the column?
  • Finally, the id and headers mapping tags for td or th. Use id for the parent, headers for the child (e.g., headers link back to id). Note that while verbose, this method is very precise and can be overkill for simpler tables. The scope attribute usually sufficient for most tables.
