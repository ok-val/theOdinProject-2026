Background shorthand

`background` (without the -color) is a shorthand for 8 different properties you can do with background.

Borders

`borders` (plural) is the shorthand for `border` and `border-radius`.
It's good to know that you can define multiple corner radii if you'd like.
Don't remember it. Just look it up whenever you need to use it.
