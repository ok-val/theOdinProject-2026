Font styling properties

Okay, let's play with some font styling for today :D

This one uses an em tag but this one uses a span with `font-style`.

The latter approach doesn't apply semantic emphasis. Use it for styling only.

`letter-spacing` is just tracking (bro, please). WIDE and NARROW.

`line-height` is just leading.

`text-transform` allows alternative casing such as uppercase or capitalize every word.

`text-shadow` is used to create shadow for visual emphasis.Use sparingly as it can cloud readability.
