## Tables

Creates a 2D matrix with the tags `<table><\table>` in which the rows and columns constructed.

As usually, iterations are wrapped by row:

```html
<table>
  <tr>
    <th>First Header</th>
    <th>Second Header</th>
  </tr>
  <tr>
    <td>This is a data cell</td>
    <td>This is also a data cell!</td>
  </tr>
</table>
```
