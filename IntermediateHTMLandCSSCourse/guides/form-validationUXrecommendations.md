## UX recommendations for form validation

**Show errors for every widgets. Don't clump them up.**

![[Pasted image 20260502155256.png]]


**Allow users to click the Submit button to check for errors. Don't disable it.**

![[Pasted image 20260502155352.png]]


**Provide positive feedback as well.**

![[Pasted image 20260502155424.png]]


**For negative or positive feedback, consider using icons, useful for color-blind users.**

![[Pasted image 20260502155612.png]]


**Use casual, relatable language. Don't use jargons.**

![[Pasted image 20260502155509.png]]


**Show password rules as immediately as possible.**

![[Pasted image 20260502155700.png]]


**Consider using polyfills to mitigate mistakes.**

![[Pasted image 20260502155823.png]]
