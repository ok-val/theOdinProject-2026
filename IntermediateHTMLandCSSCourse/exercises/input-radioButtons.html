Radio buttons

Radio buttons are preferred when the option list is short (>5).
Radio buttons are often more user-friendly by showing all the cards on the table.

Radio button is an input type (specified by the type attribute of the input element).
This is different than how the select and option elements are constructed.

Note that the radio input type uses a value attribute. It will result in a form object, comprising of [name]:[value] pair.
Also note that radio checkboxes are toggled to ensure single single selection. These are connected using the name attribute. Just make sure that associated radios use the same value for their name.
