Select dropdown

The select element renders a dropdown list where users can select an option.
Select dropdowns are preferred when the list of options are long (>5) and hierarchical.
The construction is similar to an ul with nested li.
Similar to an input element, select accepts the `name` and `id` attributes. The option element nested inside select uses a value, which if empty will default to using the innerText.

Alternatively, I can also split the list of options into groups using the optgroup (option group) element. The optgroup element takes the label attribute to show which group the option belongs to. Note that the optgroup's label is only to help users compartmentalize options. It is not sent to the backend.
