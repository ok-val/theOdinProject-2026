Select

The main issue with styling the select element is in targetting its dropdown menu arrow.

The solution would be to use our old friend appearance:none to remove this OS styling and generate our own.

However, this is not as straight-forward as it is for radios and checkboxes because ::before and ::after don't work here. We have to create a wrapper div. Set that to relative, the arrow to absolute TBLR (Top-Bottom-Left-Right) properties.

Date input types

Yes, the boxes are controllable but the pop-ups aren't.

The pop-ups cannot be overriden. So I can either create my own or use a library.

Number

For some mobile devices, number inputs usually prompt a wheel scroller.

If this is not desirable, use tel with pattern and maxlength validation instead.

Range input types

Another notoriously-difficult-to-style element. Prepare to use some advanced CSS tricks provided in this article.

File picker

The problem with this one is that its associate button cannot be styled.

The workaround is to hide the input element entirely and take advantage of the label which also activates the element.

Meters and progress bars

These are the worst offenders. Applying appearance:none to them apparently makes things worse.

MDN suggests using third-party solution such as progressbar.js. It essentially just builds one anew.
