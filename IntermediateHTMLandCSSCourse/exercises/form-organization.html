Why organize your forms?

Using the correct input types is the first step, but what if we have a larger form?
This could get overwhelming quickly. Enter fieldset and legend elements.

Fieldset element

The fieldset element is a container for grouping related input forms.
Use a fieldset for full name, another one for favorite food, and so on. Fieldset uses a block display mode by default. In the default style, it uses a grey solid border around the block.

Legend

The legend element gives fieldsets a heading or caption.
A legend should always come right after an opening fieldset tag.
