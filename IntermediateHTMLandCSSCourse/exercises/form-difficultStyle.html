The bad: Hard-to-style widgets

  • Checkboxes
  • Radio buttons
  • Input search types

The ugly: Cannot-be-styled-using-CSS-only widgets

These are the elements that can't be style thoroughly using CSS.

  • select
  • option
  • optgroup
  • datalist
  • progress (what is this?)
  • meter (what is this?)
  • color picker (input color)
  • datetime-local (input datetime-local)
  • slider controls (input range)
  • file picker (input file)

The solution: The appearance property

The `appearance` property was created to control what system-level styling was applied to widget control. For this property, the value 'none' is most commonly used to stop any system-level styling control.

See the style element nested in the head to see how these stylings are done.
