Email input type

The email input type is only for email addresses.
This is different than normal text input in that it would provide a specialized keyboard that includes an @ for users using mobile devices.

Another built-in feature is email address validation, email auto-fill (if enabled), and other browser plug-ins to recognize.

Password input type

The password input type is another specialized text input type.
It offers helpful features like asterisk (*) character masking and auto-complete (if enabled).

Number input type

The number input only accepts number values and ignores any other characters when user tries to enter. It also provides a pair of incrementing arrows for the user.

Date input type

The date input type is another special type. It provides a date picker using a calendar.
