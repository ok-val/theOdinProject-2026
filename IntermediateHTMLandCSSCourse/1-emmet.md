# Emmet

Emmet is a VS Code plugin. It helps write HTML and CSS more efficiently by using shortcuts.

## Basic Emmet

Using the `!` at the beginning of an HTML doc will create the boilerplate code.

The `Ctrl + K` shortcut helps remove tags efficiently using the caret's position. See it [here](https://docs.emmet.io/actions/remove-tag/).
