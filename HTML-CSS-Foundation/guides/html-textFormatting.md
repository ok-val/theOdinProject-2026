## Strong element

Don't just make your text element bold. This is because `bold` is NOT as semantically meaningful as `strong`. Again, mainly for indexability and accessibility, the screen reading will not emphasize the `bold` element, but do for the `strong`. 

```html
<p>I am a paragraph. Within is a <strong>strong</strong>element.</p>
```

## Em element

`Em` is for italicizing. Again, helps with emphasis in semantic markup.
