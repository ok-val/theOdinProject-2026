Flex justification

`flex-direction` is about direction.

`flex` properties are about per-item sizing.

`justify-content` is about primary-axis spacing (along-axis).

`align-items` is about cross-axis spacing (cross-axis).

e.g., for flex-direction: row; meaning primary axis set to horizontal:

  • justify-content sets horizontal spacing (along row).
  • align-items sets vertical spacing (cross row).
