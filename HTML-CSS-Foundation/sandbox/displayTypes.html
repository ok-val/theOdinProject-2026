Default display types

I'm a paragraph. I use `block` by default

  • I'm a child of an unordered list. It uses `block` by default.
  • I'm a list item. I use list-item by default.

Another paragraph with a span element. My span child uses `inline` by default.

Reassigned display types

All of this can be changed of course. p and h3 are now displayed using `inline`.

  • My parent's display has been changed to `inline-flex`.
  • And I now contain a span that is displayed as a block.

It's all getting very confusing. But all is possible.
