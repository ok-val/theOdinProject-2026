Layout mode

This is a fascinating concept about CSS layout algorithms.

CSS is comprised of different layout algorithms, known as layout modes.

The default mode is Flow layout. This mode defines the normal layouts of elements (e.g., p to block, span to inline, button to inline-block).

If a display type of an element is changed, we simply switch display algos.

The divs below are declared with the same length. But because they use different layout modes, they behave differently.
