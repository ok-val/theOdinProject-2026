About The Odin Project
  • `Target` attribute to specify where the link will be opened.
    • `_self` is assigned by default, which opens the link in the same tab.
    • `_blank` opens the link in a new tab.
  • `Rel` attribute describes the relation between the current page and the linked source.
    • `noopener` prevents the new tab from accessing the original page. This is mainly for security reasons. Most modern browsers would automatically for any links that would open a new tab.
    • `noreferrer` is the same noopener. Sometimes it is desireable to share information about the original page, sometimes it's not so I can use this option if needed.

Absolute links

Yes, there are absolute and relative links.

Absolute links are links to pages on other websites. I have seen instances of these links everywhere: https://www.theodinproject.com -- in which http is the scheme/protocol, www... is the domain name, /anything that follows is the path.

Absolute links can also just be from your own computer, starting from the root drive C://, for example.

Relative links

Relative links are links to other pages within my own website. They do not contain domain name; it just assumes that the same domain for all pages in our website, unless otherwise specified.
